# Індивідуальне завдання
---
## Мета 

Це завдання показує, як за допомогою **криптографічного підпису RSA** та **стеганографії в зображенні** можна захистити дані. Підпис не просто створюється — він **приховано вбудовується в саме зображення**, без зміни його візуального вигляду.

---

## Опис мого підходу

1. **Генерація ключів**
   - Створюється пара RSA-ключів розміром 4096 біт (приватний + публічний).
   - Зберігаються у файли `private_key.pem` та `public_key.pem`.

2. **Підпис зображення**
   - Зображення `image.png` читається у вигляді байтів.
   - Обчислюється хеш SHA-256.
   - Хеш шифрується приватним ключем — це і є **цифровий підпис**.

3. **Стеганографія (LSB)**
   - Підпис перетворюється у біти.
   - Кожен біт вбудовується у **найменш значущий біт (LSB)** пікселів зображення.
      Кожен піксель у форматі RGB складається з трьох компонент — червоного (R), зеленого (G) і синього (B), кожна з яких зберігається як байт (8 бітів).
      Найменш значущий біт — це останній восьмий біт байта. Його зміна майже не впливає на вигляд зображення, тому його можна безпечно використовувати для приховування даних.

     Приклад:
     * Значення синього каналу: 11001010 (десяткове значення: 202)
     * Використовуємо "0" для вбудовування біта підпису.
     * 11001011 (десяткове значення: 203)

     Таким чином вигляд зображення залишиться незмінним для людського ока, але підпис буде приховано в піксельних даних.
   - Нове зображення з підписом зберігається як `signed_image.png`.

4. **Перевірка підпису**
   - Зчитується підпис із LSB пікселів.
   - Перевіряється, чи відповідає він хешу оригінального зображення.
   - Якщо відповідає — зображення **не було змінено**, підпис дійсний.

## Структура проєкту
```
├── image.png
├── individual_task.py
├── signed_image.png
├── private_key.pem
├── public_key.pem
```
## Запуск програми
Для того аби успішно запустити файл individual_task.py потрібно завантажити декілька бібліотек. Тому перед початком роботи запустіть наступну команду в терміналі:
```
pip install -r requirements.txt
```

Далі потрібно запустити наступний код в терміналі:
```
python individual_task.py
```
